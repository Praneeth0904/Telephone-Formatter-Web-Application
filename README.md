## 📌 Telephone Formatter Web Application

Formats user input into a standard telephone number pattern.

---

## 🛠️ Tech Stack

HTML5 • CSS3 • JavaScript

---

## ✨ Features

* Formats user input into a valid phone number pattern.
* Ensures consistent and readable formatting.
* Handles input dynamically as the user types.
